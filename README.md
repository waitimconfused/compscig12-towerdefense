# Unit 2 Modular Programming Group Project

This is only Part 1 (version 1.0) of a multi-unit project.

Part 1 Outline: In groups of 2 to 4 people:

1. Create a software requirements document discussing the features of your completed finished program.
2. Create a modular program with classes split amongst different TypeScript files.
3. Create a graphical user interface (GUI) using an HTML Canvas.
4. Implement and expand on one of the basic designs listed below.

## Selected Option: **Tower Defense** *(Option 2)*
Bloons Tower Defense knockoff.

See gameplay video: [Bloons TD 6 - Downstream [Hard] Gameplay (No Commentary)](https://www.youtube.com/watch?v=4-cT9n8QNAk&t=31s)

Create a program where the user oversees the defense of their lands.

The enemy units move along pre-defined paths on a map.

The user plays as a god-like hand who places different stationary
towers/units on the map to try and stop waves of enemies as they
try to reach an important point on the map.

The units that the player controls vary in terms of how far they
can shoot, and how much time it takes between their shots.
